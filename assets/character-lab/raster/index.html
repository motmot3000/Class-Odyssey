Ce que ce format permet

Changer une tenue sans redessiner le personnage. Les variantes de tunique sont des calques colorimétriques tirés des PNG fournis. La tenue verte reste incluse dans la base.

Équiper et remplacer une base. Les pièces importées se superposent devant ou derrière. Une image déjà alignée sur 1 024 × 1 536 px conserve son cadrage. Une nouvelle base utilise ses propres équipements.

Préparer le jeu. Le kit fournit les PNG et un manifeste d’assemblage. L’export PNG est aplati ; l’export JSON conserve les références, les positions et les images importées. Ce test utilise une seule pose fixe.

Images sources : exports ChatGPT fournis par l’utilisateur. Détourage et couleurs préparés localement. Le nom exact du modèle de génération n’est pas disponible.
