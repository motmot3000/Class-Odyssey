## Open-source code

The original code and documentation of Class Odyssey are released under the
**MIT license**. The license allows use, modification and redistribution under
its terms, including keeping the notice.

[MIT text](https://github.com/motmot3000/Class-Odyssey/blob/main/LICENSE) ·
[Third-party notices](https://github.com/motmot3000/Class-Odyssey/blob/main/THIRD_PARTY_NOTICES.md)

`"private": true` in `package.json` prevents an accidental npm publication; it
is not the visibility setting of the GitHub repository.

## Media and third-party components

The code license does not relicense third-party fonts, dependencies, models or
textures. Barlow and Chakra Petch keep their OFL license, and libraries keep
their own notices. Some media have an import chain or a license that still needs
clarification: a neutral visual description is not provenance.

Work in Blender may combine original creation and adaptation of sources. Do not
present all media as MIT on the sole basis of the JavaScript license or the
repository's visibility.

The [technical inventory](https://github.com/motmot3000/Class-Odyssey/blob/main/docs/assets-and-licenses.md)
identifies asset families and their provenance documents, separately from the
game presentation. Existing notices are kept for traceability.

## For a graphic contribution

State the author, the source, the exact license and the creation method; include
the authorised sources and the regenerated outputs. A free or downloadable model
is not necessarily redistributable or modifiable. For an original creation,
state its media license explicitly.

The MIT license also grants no trademark or official endorsement right from the
author or third parties. See [Contributing](Contributing).
