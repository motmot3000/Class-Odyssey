# Bienvenue dans Class Odyssey

**Une aventure de classe pour rendre la progression visible, sans ralentir le cours.**

Class Odyssey est une application web conçue initialement pour les cours d'anglais
de 7P/8P. L'enseignant pilote les récompenses et la progression ; les élèves
retrouvent leur héros, ses niveaux et sa personnalisation sur le tableau de classe.
L'univers graphique est celui de l'aventure fantasy : héros stylisés, tenues,
accessoires et silhouettes humaines ou elfiques.

## Un projet jeune, une invitation à contribuer

Le socle est déjà conséquent, mais le projet reste en début de développement.
Une partie du code a été **« vibe codée »**, avec l'aide d'outils d'IA.
Cela fait partie de son histoire, sans dispenser de comprendre, relire et tester
chaque changement. Les contributions sont les bienvenues, techniques ou non.

Thomas Wünsche vise un outil fonctionnel et utilisable, et en assure le suivi
et la consolidation au fil du temps, **selon les disponibilités de son agenda**.
Il ne promet ni permanence de support, ni calendrier de livraison, ni surveillance
de sécurité continue. Lire [Projet et pérennité](Projet-et-perennite).

Le code original et la documentation sont **open source sous MIT**.
