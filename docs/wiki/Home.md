# Class Odyssey

**Classroom gamification, one hero per student.**

Class Odyssey is a web app that turns a class into a shared adventure. Every
student has a 3D character — a hero — that grows with them: XP, levels, hearts
and virtual coins. The teacher projects the class on the classroom screen and
runs the lesson from a protected console. Rewards, consequences and progression
happen inside the platform, in front of the class, without slowing the lesson
down.

The design is deliberately inspired by **Classcraft**. Classcraft is far more
developed: more features, more years of classroom use, a full team behind it.
Class Odyssey is an independent, early-stage project built around the same core
idea — one persistent character per student, visible progress, and a teacher who
can reward or sanction in a single click. It is not a replacement for Classcraft
and does not claim to match it.

## A young project, open to contributions

The foundation is already substantial: teacher accounts, classes, 3D heroes, XP
and levels, HP, a virtual shop, French and English interfaces, server
persistence and an operator console. The project is still at an early stage and
not everything is stabilised.

Part of the code was **vibe coded** with AI tools. That is part of its history,
and it does not remove the need to read, understand and test every change.
Contributions are welcome, technical or not.

The project is maintained by **[@motmot3000](https://github.com/motmot3000)**,
who keeps it usable and consolidates the code, dependencies and documentation
**as time allows**. There is no guaranteed support, no delivery calendar and no
continuous security monitoring. Read [Project and maintenance](Project-and-maintenance).

The original code and documentation are **open source under MIT**. Dependencies
and third-party media keep their own rights: [Licenses and assets](Licenses-and-assets).
